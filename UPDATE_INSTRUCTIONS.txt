HP20 v0.9.5 PROVISIONING UX + OTA
=================================

LOCAL FIRST BOOT
1. Copy secrets.example.h -> secrets.h.
2. Điền WIFI_SSID / WIFI_PASSWORD / TB_TOKEN / TB_CA_PEM trực tiếp trên máy.
3. PROFILE_REVISION=1 cho lần áp local đầu tiên; tăng 2,3,... chỉ khi muốn local profile ghi đè NVS đúng một lần.
4. secrets.h đã bị .gitignore chặn; KHÔNG git add -f file này.
5. Arduino IDE: Verify -> Upload.
6. Boot: revision local mới hơn revision đã lưu -> apply một lần vào NVS và tự kết nối.

MOVE / CHANGE WI-FI
- Giữ BOOT ~3 giây -> mở portal.
- Portal lưu mạng mới vào NVS.
- NVS có ưu tiên cao hơn secrets.h, nên reboot/mất điện tiếp tục dùng mạng mới.

OTA
- Mặc định OFF. Bật qua portal Advanced hoặc secrets.h.
- ThingsBoard OTA package title phải là HP20.
- Version package phải lớn hơn firmware hiện tại.
- Chọn SHA-256.
- Serial command OTA = kiểm tra ngay.

VERSION
- Chỉ sửa hp20_version.h.
